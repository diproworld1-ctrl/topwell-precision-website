# Topwell Precision — Website

Clean industrial B2B website for Jiaxing Topwell Precision Machinery Co., LTD.
Sheet metal fabrication: tube laser, bending, welding, assembly.

**Live site:** https://diproworld1-ctrl.github.io/topwell-precision-website/

## Pages

- **index.html** — Homepage (hero, capabilities, products, process, quality, why us, CTA)
- **capabilities.html** — Full capabilities + tolerances + materials
- **products.html** — 4 product families with spec tables
- **quality.html** — Tolerances, inspection process, certifications
- **about.html** — Company story, factory, location
- **contact.html** — Quote form (Formspree) + contact info

## Colors
